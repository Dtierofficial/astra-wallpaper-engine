# Установка в Astra

1. Открой Astra → Мастерская / Плагины → импорт плагина из файла.
2. Выбери **`E:\AstraWallpaperEngine\wallpaper-engine-1.1.1-noarch.astraplugin`**.
3. Подтверди импорт собственного локального пакета и включи плагин. Приложение может запросить разрешение на неподписанный локальный код; это решение принимается в интерфейсе Astra, настройки безопасности автоматически не изменяются.
4. Открой страницу **Wallpaper Engine** в навигации Astra.
5. Выбери видео, картинку или Web-проект, затем нажми **Применить в Astra**. Для Web нужно подтвердить доверие авторскому JavaScript.

Плагин не скачивает обои: он использует уже скачанные файлы Steam. Сцены (`scene.pkg`) пока только в каталоге. Web поддерживается экспериментально, без внешней сети и нативных API WE.

Если галерея пуста, укажи корневую папку Steam в настройках плагина (например `D:\Steam`), сохрани настройки и нажми «Обновить».

После импорта проверь **версию 1.1.1** в карточке плагина и нажми «Перезапустить». Старую вкладку закрой и открой заново. Разрешение `push_to_ui` нужно для остановки при скрытии/сворачивании нативного окна. Оно не даёт доступа к диалогам.

Вверху панели есть выбор языка: «Автоматически (Astra)», English, Русский. По умолчанию используется язык Astra, независимо от языка Windows. До получения языка — только экран загрузки на английском. Ручной выбор сохраняется; чтобы снова следовать Astra, выбери «Автоматически (Astra)». Это один пакет, а не отдельные русская и английская сборки. Поддерживаются Windows x64 и Astra 0.2.7+.

В 1.0.2 исправлены схлопывание сетки до полос и размещение фона: плеер находится над штатными обоями, но под содержимым Astra. Порядок слоёв настраивается через публичный мост; при снятии обоев прежнее значение восстанавливается. Совместная работа с другими плагинами, меняющими `--z-plugin-front`, не проверена.

Если фон не виден: выбери именно видео, попробуй другой MP4 (кодеки отличаются), посмотри статус плеера после применения. Проверка в тестовом стенде не заменяет проверки живой Astra.

Статус рендерера также записывается в `%LOCALAPPDATA%\AstraWallpaperEngine\renderer-status.json` (без токенов подключения). Его можно приложить для диагностики; там может быть локальный путь выбранных обоев.

Для переноса сохранённых настроек другого монитора выбери Monitor0 / Monitor1 в инспекторе. «Заново взять настройки WE» удаляет только переопределения этого плагина.

Личные настройки плагина хранятся в `%LOCALAPPDATA%\AstraWallpaperEngine\settings.json`. Исходные настройки Wallpaper Engine не изменяются.

**Важно:** 1.0.2 подтвердил работающим пользователь. Для 1.1.0 пройдены тесты RU/EN, изображений/Web, протокола и нативного скрытия/сворачивания тестового окна Windows. Совместную работу нового пакета в реальной Astra ещё нужно проверить. Защита daemon не обходилась.
