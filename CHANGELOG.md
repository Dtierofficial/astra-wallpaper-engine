# 1.1.2

- Node.js 24.22.2 LTS для Windows x64 включён в пакет. Установка системного Node.js, npm и настройка PATH больше не нужны.
- Сборка получает runtime только с официального nodejs.org, проверяет закреплённые размер и SHA-256, сохраняет полные лицензии Node и его компонентов. При запуске загрузок нет.
- Путь запуска указывает на встроенный `dist/runtime/node.exe`; настройки и избранное остаются в прежнем профиле.
- Добавлены проверки повреждённых загрузок и запуска распакованного пакета без Node в PATH, исходников и node_modules.

# 1.1.1

- При запуске язык интерфейса определяется только языком Astra (или ранее выбранным вручную RU/EN), а не языком Windows/браузера.
- До получения языка от Astra отображается только нейтральный экран загрузки на английском; элементы галереи появляются уже на нужном языке.
- Добавлены браузерные проверки: English Astra + русский браузер, Russian Astra + английский браузер, сохранённое ручное переопределение, смена языка Astra без перезапуска, English fallback для остальных языков.

# 1.1.0

- Один пакет с RU/EN интерфейсом, автоязыком Astra и ручным переключателем. Неизвестные языки используют English. Локализованы сообщения и подписи, а не только карточка в каталоге.
- Добавлены отдельные изображения/GIF и экспериментальные локальные Web-обои. Scene/PKG остаются неподдерживаемыми.
- Web-проекты работают в отдельном sandbox iframe/HTTP origin, без моста Astra и токенов плагина. Разрешено читать только выбранный каталог, внешние запросы и вложенные фреймы блокируются CSP. Нужно явное подтверждение доверия.
- Переносятся пользовательские свойства Web, FPS и приблизительные аудиополосы; часть типов свойств редактируется в инспекторе.
- Нативный read-only монитор Windows проверяет видимость `astraui.exe`, передаёт события через `push_to_ui`. Свернутое/скрытое окно освобождает рендер, восстановленное — возобновляет. Пакет теперь Windows x64, так как содержит этот помощник.
- Добавлены тесты словарей, sandbox Web, локальных assets, свойств, RU/EN и нативного окна.

# 1.0.2

- Воспроизведена регрессия 1.0.1: высота строк CSS grid падала до 4px. `grid-auto-rows: max-content` и минимальная высота карточки исправляют сжатие.
- Убрано перестроение галереи при простом выборе карточки. Применение сохраняет прокрутку.
- Установлено: `background.behind` имеет z=-1, а `.main-layout` непрозрачен. Фон перенесён во фронтальный слот с уровнем 1 через публичный bridge. Штатные обои находятся на 1 и идут раньше, контент находится на 2.
- Добавлено восстановление прежнего уровня слоя на отключении и скрытии, защита от устаревшего ответа `play()`.
- Статус плеера привязан к выбранному файлу. Выбор больше не выдаётся за успешное проигрывание.
- Добавлен sandbox/browser regression test с 155 синтетическими карточками и generated WebM, без реальных пользовательских изображений.
- Реальная установка нового пакета в Astra остаётся ручным этапом. Scene/PKG и Web playback не добавлены в эту версию.
